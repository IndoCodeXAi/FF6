# FF6 Advance

Aplikasi pembungkus mGBA (libretro) dengan fitur Import Game.

1. Upload seluruh isi folder ini ke repositori GitHub (branch `main`).
2. Buka tab Actions, jalankan workflow "Build APK" (otomatis jalan saat push).
3. Unduh artifact `FF6Advance-APK`, ekstrak, lalu pasang `app-release.apk`.
4. Di app: Import Game, pilih file .gba milikmu, lalu ketuk untuk bermain.
